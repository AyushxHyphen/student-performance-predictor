*Student Performance Predictor ( Edu-Predict )


Live Demo: https://ayushxhyphen.github.io/student-performance-predictor/

A machine learning–based web application that predicts whether a student will pass or fail, based on academic and demographic factors. The project uses a dataset sourced from Kaggle containing 1,000 student records, and combines data analysis with a simple, browser-based interface for generating predictions.


*How It Works

The dataset (1,000 samples) is sourced from Kaggle and includes academic and demographic attributes relevant to student performance.
Pandas is used for Exploratory Data Analysis (EDA) — cleaning, inspecting, and understanding patterns and relationships in the data.
NumPy handles numerical computations within the dataset (e.g., array operations, statistical calculations) to support the ML pipeline.
A machine learning model is trained on this processed data to classify outcomes as PASS or FAIL.
The frontend, built with HTML, CSS, and JavaScript, provides a simple form-based interface where users can input details and receive a prediction.

*Tech Stack

Language: Python
Data Analysis: Pandas (EDA), NumPy (numerical computation)
Machine Learning: Custom-trained classification model
Algorithm: Random Forest ( Best Results )
Frontend: HTML, CSS, JavaScript
Dataset: Kaggle (1,000 records)
Deployment: GitHub Pages

*Key Features

Predicts student PASS/FAIL outcomes using academic and demographic input data
EDA-driven data preprocessing for cleaner, more reliable predictions
Lightweight, easy-to-use web interface (no frameworks — vanilla HTML/CSS/JS)
End-to-end pipeline from raw Kaggle data to live prediction
